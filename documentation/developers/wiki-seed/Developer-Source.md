# Developer Source

This page is the contributor starting point for StreamerOps.

## Repository Layout

- app/: React application, pages, components, and platform features
- server/: API, adapters, and backend integration points
- scripts/: utility scripts and checks
- documentation/: architecture, API, and guide content

## Local Setup

1. Install dependencies: npm install
2. Start frontend: npm run dev
3. Start backend (if needed): npm run server
